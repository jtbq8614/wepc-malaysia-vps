## 下单前确认这 6 件事

**1. IP 是静态还是动态。** 问法很直接：这台机的 IP 会不会变、多久变一次。做账号环境必须静态，做采集或临时用途动态也能接受。动态 IP 配固定白名单的业务会直接崩。

**2. 流量是单向还是双向计费。** 2TB 月流量如果是双向计，实际可用只有一半。直播推流这类上行吃流量的场景，差别很大。

**3. 100Mbps 是共享还是独享。** 共享带宽在晚高峰会掉速。产品页写“共享”就要按打折预期规划。

**4. Windows 是否另收授权费。** 官网有 Windows 产品分类，但授权费是否包含在标价里没有明确写。结账页看到额外 License 行就是另收。

**5. 月付价和年付折合价差多少。** Mondoze 那个例子最典型：年付折合 8.33 美元/月，月付接近 30 美元/月。只看折合价会误以为能按月付这个价。

**6. 续费价和退款窗口。** 首期价和续费价不同价是行业惯例。同时确认退款天数、是否有不可退的机型（WePC 的 HK_3CMI 就不退）、退款是否扣手续费。

**住宅 IP 和机房 IP 怎么选？**

**月付还是年付？**
新商家、新线路，先月付。跑够两周确认延迟、丢包、IP 稳定性，再考虑年付锁价。年付的折扣要用“能不能承受这家跑路或线路变差”来换。

**Windows VPS 要不要额外加钱？**
WePC 有独立的 Windows VPS 产品分类，但现有资料没有明确说明授权费是否包含。下单页看到额外 License 项就是另收，没有就是含在标价里。这一项必须在结账页确认，不能靠猜。
